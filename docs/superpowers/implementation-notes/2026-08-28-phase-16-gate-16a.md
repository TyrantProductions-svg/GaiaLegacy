## Empty DETAIL clarification

The shared non-null empty DETAIL sentinel is not a persistent or canonical parent-cell state.

- Sparse physical DETAIL storage contains only entries whose `occupancyMask != 0`.
- Absence of a sparse entry means the canonical representation is FULL.
- FULL AIR is `FullCellState((byte) 0)`.
- Clearing the final occupied subvoxel will atomically convert DETAIL to FULL AIR in Gate 16B; Gate 16A establishes the replacement seam but does not expose a production mutation service.
- Placing the first subvoxel into air will atomically convert FULL AIR to DETAIL in Gate 16B.
- Gate 16A stores no empty `DetailStorage` or empty `DetailCellState` in a Chunk or snapshot.
- A shared non-null empty object may be returned only as a non-owning immutable API/view. It is never installed as canonical state, serialized, revision-authorized, meshed, raycast as DETAIL, or collision-authorized.
