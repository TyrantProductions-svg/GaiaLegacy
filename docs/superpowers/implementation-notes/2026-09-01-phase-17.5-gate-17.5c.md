## Implemented direction

The runtime title screen uses A+ (70% Gaia Panorama, 30% restrained Orbital
Legacy): the project-owned Gaia terrain capture remains the emotional focus,
while the left directional shade, low-contrast celestial body, broken orbit
arcs, and lower-right topographic/DETAIL marks provide secondary identity. The
initial project-owned wordmark was assembled through the UI command path from a
broken planetary ring, terrain horizon, 2x2 DETAIL cue, strong Pixelify `GAIA`,
smaller Inter `LEGACY`, and a restrained divider. The primitive emblem and faint
sky cue are superseded by the focused human-review correction recorded below.

The Main Menu is deliberately minimal: `NEW WORLD`, `WORLD ARCHIVE`, `SETTINGS`,
`CONTROLS`, and `QUIT`, plus small channel and version lines. `CONTINUE` is not
fabricated because the current product shell has no canonical Continue action.
At the 854x480 default runtime surface, the navigation top is derived from the
available height so all actions remain above the footer.

Settings, New World, World Archive, pause, and confirmation states keep the
same Gaia hero perceptually present but apply the darker structured overlay.
Gameplay remains world-first: inventory/body slots, mode, DETAIL state, and
failure notices retain the existing lightweight HUD ownership and bounds.

## Rendering and residency

- The existing `UiRenderer`, shader, batcher, texture lifecycle, and owner
  thread remain the only UI rendering authority.
- Runtime typography remains one logical `TypographyCatalog` backed by two
  physical pages: 256x512 Pixelify display (524,288 RGBA8 bytes, NEAREST) and
  256x256 Inter body/HUD (262,144 RGBA8 bytes, LINEAR).
- Three deterministic 1280x720 hero derivatives are packaged, each 3,686,400
  decoded RGBA8 bytes. The vertical slice binds only the initial `dawn` page,
  so runtime hero residency is one page (3.52 MiB), not all three.
- The static vertical slice adds one fullscreen hero draw command and one hero
  texture binding at the start of a product-screen frame. It does not decode
  per frame, browse the filesystem, own a world, or add a shader.
- `highlands` and `twilight` establish the deterministic future roster. Slow
  pan/crossfade and two-slot current/next residency remain a clean follow-up;
  they were not forced into this review slice.

## Human-review correction: smooth emblem and ringed planet

Scope: these two visuals only. No gameplay, navigation, hit region, font, HUD,
motion, shader or renderer ownership change. Gate 17.5D is not started.

### Brand asset

Canonical project-owned vector/path source:
`tools/src/main/java/com/gaia/tools/ui/RuntimeBrandAssetGenerator.java`.
Analytic circular ring, stroked cubic terrain/horizon, and a small 2x2 cue are
rasterized with 4x4 subpixel coverage and a deterministic box downsample.
The generator runs at build time only; no runtime SVG engine is introduced.

Outputs: `game/src/main/resources/assets/gaia/ui/brand/gaia-emblem.png` and
`brand-manifest.json`. The single page is 256x256 RGBA8, LINEAR, 262,144 bytes,
with at least 16px transparent padding. All transparent and partially covered
pixels retain ink RGB `91dce8`; coverage is stored in straight alpha. Existing
SRC_ALPHA / ONE_MINUS_SRC_ALPHA blending and CLAMP_TO_EDGE are unchanged.

`BRAND_EMBLEM` joins the existing UiAssetBundle/UiRenderer texture map. It replaces
12 primitive emblem commands with one white-tinted textured quad. The title
quad is logical [70,46]-[166,142]; GAIA/LEGACY text and navigation positions
remain unchanged. Expected main-menu delta: -11 UI commands, +1 batch draw and
+1 texture binding relative to the previous adjacent-solid batch. Other screens
do not draw the emblem. No per-frame asset decode or upload is added.

### Celestial layer

`RingedPlanetLayer.java` is project-owned parametric build-time geometry. Each
1280x720 hero receives a 200px sphere centered at (1040,132), shaded with a
directional spherical light, subtle bands and a feathered limb. Body alpha is
approximately 39-52/255 before limb feathering. Elliptical rings have a 430x112
outer ellipse tilted -15 degrees, three thin bands with gaps, and alpha 30-43/255.
Front-ring overlap may be slightly stronger after compositing.

The back ring is geometrically hidden by the sphere before atmospheric opacity;
the near ring crosses the front. Both are 4x supersampled into the source hero,
not runtime geometry. Four prior arcs become two faint short accents (8/255 and
6/255). Lower-right topo/DETAIL treatment is unchanged. Hero residency stays one
1280x720 page (3,686,400 decoded bytes); planet memory/draw/bind delta is zero.
