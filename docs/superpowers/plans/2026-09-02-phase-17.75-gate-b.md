# Phase 17.75B Headless HAND_TOOL_V0 Validator Implementation Plan

> **For agentic workers:** Execute task-by-task with Superpowers TDD and verification-before-completion. User authorization overrides workflow defaults: no Git integration, worktree, Blender or viewer. Independent subagents review after GREEN; they do not modify files.

**Goal:** Validate admitted self-contained hand-tool GLBs headlessly and publish deterministic reports and immutable validated snapshots.
**Architecture:** Existing bounded preflight and strict mapper remain the sole input boundary. One tools-only validator coordinates bounded buffer, scene, geometry and material/image checks. CLI/report adapters never define their own rules.
**Tech Stack:** Java 17 API/bytecode on JDK21; existing isolated source sets; admitted JglTF 3.0.1/Jackson 2.22.1 only; standard headless ImageIO.
**Spec:** `docs/architecture/gaia-glb-hand-tool-v0.md` and `docs/superpowers/specs/2026-09-02-phase-17.75-model-inspector-design.md`.

## Global constraints / controller clarification

- Gate A is controller-approved; do not restart it or weaken its parsing semantics.
- Baseline `d3a219767b2a16c6f4e5f7514019c56ca9cf6cf7`; primary checkout, branch `codex/phase-17-75-contract-admission`.
- Unique geometry counts ALL declared primitives, including unreachable ones. Each primitive contributes its POSITION count even when another primitive shares that accessor.
- Expanded geometry counts every reachable default-scene node/mesh/primitive instance, without copying geometry arrays. Both domains cap triangles at 10,000 and vertices at 30,000. Each independently warns when triangles > 4,000 and <= 10,000. Invalid graph and unreachable payload remain independent errors.
- Proper rigid transforms only: translation/rotation allowed; scale/reflection/shear/singularity/non-finite rejected. `RIGID_TRANSFORM_EPSILON = 1e-4` applies to norm/length versus one, pairwise dots versus zero, determinant versus +1 and affine constants. No normalization or rewriting; no new axis/sidecar/Blender-proof requirement.
- Other frozen limits: 16 MiB GLB, 1 MiB JSON, 64 nodes, depth 16, 8 meshes, 16 primitives, 8 materials, 4 PNG/JPEG images, 1024x1024 per image, 16 MiB decoded RGBA aggregate. No extensions/sparse/skins/animations/morphs/cameras/lights.
- Existing runtime authorities, dependencies and user-owned quarantine/dist bytes remain unchanged. No production assets or downloaded fixtures.

## File ownership and planned interfaces

### Gate 17.75B controller contract clarification — primitive attribute allowlist

Tasks 6/7 now enforce exactly POSITION + NORMAL + optional TEXCOORD_0; UV0 is
required for base-color textures, whose texCoord must be absent or zero.
COLOR_n fails as UNSUPPORTED_VERTEX_COLOR; other legal unsupported attributes
fail as UNSUPPORTED_ATTRIBUTE; malformed semantics fail as INVALID_GLTF_ATTRIBUTE.
No payload decode is needed to reject a semantic. Snapshot fidelity forbids
silently discarding appearance-affecting attributes.

To test this through the COMPLETE validator entry point, Task 6 brings forward
the thin coordinator/result publication seam from Task 9. Task 9 still owns the
final whole-model snapshot/immutability audit. Execute attribute negatives through
GaiaGlbValidator.validate(InputStream), then geometry positive controls, then the
material/image positive controls in Tasks 7/8. No intermediate partial check is
advertised as full Gate B validation or used to approve assets.

Permanent PrimitiveAttributesTest cases: COLOR_0, COLOR_1, color with baseColor,
TANGENT, TEXCOORD_1, JOINTS_0, WEIGHTS_0, _ATTRIBUTE, malformed semantics,
deterministic ordering, POSITION/NORMAL with optional unused UV0, textured
default/explicit UV0, and nonzero texture set rejection. Each failure must
assert the stable diagnostic/path and absent snapshot.

All new Java files live in `tools/src/modelInspector/java/com/gaia/tools/model/`; all tests in the matching `modelInspectorTest` package.

| File | Responsibility / interface |
|---|---|
| `HandToolProfile.java` | One versioned semantic budget/tolerance authority; checked count arithmetic |
| `ValidationReport.java` | Immutable outcome and bounded ordered diagnostics; `GaiaGlbValidator.Result` groups report, statistics and optional validated snapshot |
| `ValidatedModelSnapshot.java` | Defensively owned geometry, materials, images, node transforms and bounds; no DTO/files/GPU |
| `GlbAdmission.java` | Narrow package-local admitted-data handoff from the same existing strict path; public receipt stays admission-only |
| `BufferAccess.java` | Validate buffer/view/accessor relations before bounded numeric/index decode |
| `RigidTransform.java` | Pure TRS/matrix checks and uncorrected column-major transform math |
| `SceneChecks.java` | Bounded default-scene/root/reference/cycle/depth traversal and instance transforms |
| `GeometryChecks.java` | Actual finite geometry, required attributes, triangle/normal consistency, primitive accounting and actual bounds |
| `MaterialTextureChecks.java` | Frozen PBR subset, UV requirements, textures/samplers and embedded image admission |
| `EmbeddedImages.java` | Metadata-first PNG/JPEG recognition, budget reservation, bounded full decode |
| `GaiaGlbValidator.java` | Single coordinator; only publishes snapshot after no errors |
| `ValidationReportWriter.java` | Deterministic text/JSON with no timestamps, paths or exception text |
| `ModelInspectorMain.java` | Explicit-one-file CLI; testable `run` plus thin `main` |
| `SemanticFixtures.java` (test only) | Project-owned bounded byte builders; no opaque downloaded models |

## Execution protocol

For each task: write the described behavioral tests, run its focused command and record the intended RED, implement only that unit, rerun GREEN plus preceding adjacent suites. Missing intended API compile failure is allowed as initial RED; harness/import errors are not. No production implementation before RED. No commits at task boundaries.

All focused commands append `--console=plain --no-daemon`. Use the existing process-local JDK selector fallback if required; no repository/machine JDK changes.

## Stop conditions

### Controller-authorized six-finding closure sequence

No new dependency, Gate A restart, viewer, Blender or Git operations. Original
review remains 1C/3I/2M historical evidence. Image Profile v0 is now normative in
HAND_TOOL_V0; chunk/marker limits are both 256.

1. New `ImageProfileClosureTest` and test-only `ImageFixtures`: full-validator
   profile attacks/positive controls, run RED. Package-private decoder injection
   through the same coordinator and new `ImageContainers` bounded PNG/JPEG
   preflight/neutral memory input. GREEN image suites before continuing.
2. Full-path image reuse/duplicate-definition/budget tests; images[i] exactly
   once, not per texture. GREEN before color changes.
3. Raw RGB/RGBA sample and restricted JPEG known-pixel tests; raster extraction
   instead of color-managed conversion. GREEN.
4. `SceneChecksTest` full-path regressions: global parent relation, all scene
   roots parentless, default-only expansion. RED/GREEN.
5. `ValidationReportWriterTest`: hostile control characters and Unicode; one
   text escaping adapter preserving canonical diagnostics. RED/GREEN.
6. `PrimitiveAttributesTest`: custom syntax classification only. RED/GREEN.
7. `ProfileAndReportTest`: bounded canonical identity before display shortening,
   common-prefix/count/length truncation truthfulness. RED/GREEN.
8. Fresh `:tools:modelInspectorTest --rerun-tasks` and `:tools:check --rerun-tasks`
   with --console=plain --no-daemon; exact totals, independent JVM JSON, headless,
   isolation/license/hash evidence and file safety audit.
9. Four NEW read-only reviewers (image bounds, fidelity, scene/diagnostics,
   CLI/architecture), then skeptical review if 0C/0I. At most two additional
   Important/Minor RED/GREEN/re-review cycles; new Critical/profile ambiguity stops.
   Record notes/handoff and STOP before C. No reuse of 247-test closure evidence.

New material PASS/FAIL contract ambiguity, Gate A flaw, verified Critical, new parsing/image dependency, external dereference, unbounded decode, runtime contamination, Blender/viewer necessity or more than two correction cycles: STOP. Never weaken the profile to make a test pass.
