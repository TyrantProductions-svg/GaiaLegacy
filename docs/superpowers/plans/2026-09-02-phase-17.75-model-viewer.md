- No engine/game/Blender change, viewer asset approval, Gate E or new dependency.

  `Result.snapshot()` is present only after PASS/PASS_WITH_WARNINGS.

  texture index, Texture image/filter/wrap, Image canonical RGBA8, actual Bounds

  modelViewer configurations, include modelInspector output, existing inspector
  runtime dependencies and engine only. Test JUnit version follows tools 6.1.1.
- Java release 17; current local JDK21. Dedicated GLSL410 classpath resources.
- All GL on main/context thread, one synchronous coalescing reload flag, current
  plus candidate maximum. At most one GPU image per declared snapshot image;
  independent sampler objects preserve repeated-reference sampler differences.
- No JglTF import, ImageIO decode or profile revalidation in viewer code.
- Preserve model coordinates, rigid world matrices and snapshot SHA. CPU packing
  failures are presentation failures, not new HAND_TOOL_V0 acceptance semantics.
- Quarantine/dist SHA-256 must remain exactly the controller-supplied values.
