## TDD evidence

RED first established that no main-menu concept generator existed. The focused
test failed to compile with six missing references to
`MainMenuVisualConceptGenerator`, which was the intended absent API.

GREEN added a build-only deterministic software compositor that validates the
exact hero source, reuses the accepted Pixelify/Inter glyph rasterization, uses
one closed menu model, and writes only to
`tools/build/phase-17.5-main-menu-concepts/`. The test then exposed an overly
strict environmental-color threshold for the intentionally dark concept. Direct
pixel inspection and sampled-color measurement showed that Dark Signal retained
1,118 distinct sampled RGB values and visibly retained the terrain; the test was
narrowed to require more than 1,000 rather than forcing the dark treatment to
match the brighter concepts.

Final focused verification covered two concept tests and two adjacent typography
tests. `verifyPhase175MainMenuConcepts` launched two independent JVM generator
processes and byte-compared all outputs.

```powershell
.\gradlew.bat :tools:test `
  --tests 'com.gaia.tools.ui.MainMenuVisualConceptGeneratorTest' `
  --tests 'com.gaia.tools.ui.TypographySpecimenGeneratorTest' `
  :tools:generatePhase175MainMenuConcepts `
  :tools:verifyPhase175MainMenuConcepts `
  --console=plain --no-daemon
```

Result: `BUILD SUCCESSFUL` in 15 seconds.

## Runtime and resource audit

One 1280x720 RGBA8 hero texture is 3,686,400 bytes (3.52 MiB). A two-texture
crossfade peak is 7,372,800 bytes (7.03 MiB). The three review PNGs total
2,141,901 compressed bytes; review PNG size is not runtime texture memory.

The existing UI shader already samples a texture and applies tint/alpha, and
`UiRenderer` already owns UI texture creation, batching, binding, and cleanup.
The proposed runtime implementation therefore needs only a narrow hero
texture-page binding across `UiTextureId`, `UiAssetBundle`, and `UiRenderer`,
plus two fullscreen commands during a crossfade. It does not require a shader
change, second renderer, second World, simulation, save semantics, or
`ChunkRepository` ownership. Only current and next images should coexist.

## Recommendation and stop

Use Concept A's visible, inviting Gaia landscape and minimal hierarchy as the
base, with Concept B's broken orbital arcs applied more sparsely as the Legacy
motif. Reserve Concept C's stronger dark treatment for secondary/modal states or
special presentation, because it intentionally yields too much of the title
screen's emotional weight to the overlay.

The selected combination is A+'s visible Gaia landscape and minimal hierarchy,
with only B's sparse broken-orbit language. Concept C remains a secondary-screen
influence. This approval authorized the bounded Gate 17.5C vertical slice, not a
broad product-screen migration.
