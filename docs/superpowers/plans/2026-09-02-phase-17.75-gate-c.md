# Gate 17.75C — bounded Blender export implementation plan

> Execute task-by-task with Superpowers TDD and verification. Existing branch only;
> the controller prohibits all Git integration, .blend saves and Gate D work.

**Goal:** Two project-owned ephemeral Blender fixtures exported twice, with exact
file/receipt/report binding and acceptance by the unchanged Gate B validator.

**Architecture:** Dedicated temporary Scene, direct-members-only authorized
GAIA_ASSET_WORKSPACE, official Blender glTF operator with explicit settings;
separate Python provenance adapter invokes the existing headless Java CLI. No
second semantic validator. No optional texture in these two bounded probes.

**Tech:** Actual Windows Blender 5.1.2 / official exporter 5.1.20 / Python 3.13.9;
Python standard library, existing isolated Java17-compatible Gate B. No dependency.

**Spec:** `docs/architecture/gaia-glb-hand-tool-v0.md` and controller Gate C prompt.

## Frozen constraints and audited decisions

- GAIA_ASSET_ROOT; POSITION/NORMAL/UV0 only. Gate B owns all semantic rules.
- No .blend save, preferences changes, external assets, viewer or runtime changes.
- Only direct explicitly owned workspace members; nested/linked/shared ownership
  is rejected rather than recursively incorporating unrelated collections.
- A dedicated temporary scene contains only this collection. Selection/visibility
  are not source authority. Original user scene is restored in finally.
- Ruler mesh authored dimensions Blender XYZ=(1.0,0.02,0.02) meters; glTF Y-up
  conversion gives the same dimension triplet. Rigid translation is permitted.
- Tool probe: two simple closed boxes for grip/tip, with UV0 and two opaque
  metallic/roughness materials. No final chisel/artistic/runtime approval claim.
- Compare actual Gate B bounds with independent expected values, tolerance 1e-6 m.
- Outputs only new runs below tools/build/model-inspector/staging/gate-c; existing
  output collisions, traversal and link escapes reject before exporter invocation.
- Canonical receipts omit paths/time/user; source mode is
  GENERATED_EPHEMERAL_BLENDER_WORKSPACE, never a fictional .blend digest.
