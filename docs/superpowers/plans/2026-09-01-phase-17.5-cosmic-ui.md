# Phase 17.5 Cosmic UI Implementation Plan

## Final integration scope amendment

The controller accepted the corrected A+ vertical slice and manual resize.
This historical task plan is not authorization for further mass migration.
The final runtime uses two font pages, one static dawn hero and one smooth
brand texture; `HeroPresentationState`, pan/crossfade and parallax were not
implemented. Lucide/Kenney imports remain deferred (existing project-owned
icons are reused). Major animation/presentation polish is deferred until after
Milestone 2 core completion. Final verification and integration status are in
`docs/agent-handoffs/phase-17.5-handoff.md`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` (recommended) or
> `superpowers:executing-plans` to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, provenance-audited Gaia typography and icon
foundation, obtain human approval of a real Quiet Rune/Pixelify+Inter/Pixelify+Plex
specimen, and then migrate the existing UI through the approved Gate 17.5B-E
sequence.

**Architecture:** Keep one logical Gaia typography system and the existing
`UiRenderer`/`TextRenderer` authority while permitting one or more physical
atlas pages with page-specific sampling. The build-only `tools` module owns
source validation, rasterization, packing, specimen generation, and derivative
hashes; normal gameplay reads only packaged PNG/JSON resources. Game-owned
semantic roles select immutable engine text styles and never select source
files directly.

**Tech Stack:** Java 17 source compatibility, JDK 21 build runtime, Gradle 8.5
wrapper, LWJGL 3.3.3 STB, strict JSON/Gson, JUnit 6, PNG RGBA8, OpenGL 4.1 / GLSL
410.

**Spec:** `docs/superpowers/specs/2026-09-01-phase-17.5-cosmic-ui-design.md`

## Global Constraints

- Work only on `feat/cosmic-ui-typography` in the primary checkout.
- Preserve exactly one UI renderer, one text-rendering authority, one product
  screen/navigation system, one HUD path, and stable logical hit regions.
- Freeze one logical Gaia typography system backed by 1-N deterministic physical
  atlas pages; the measured specimen selects the initial page count.
- Do not add a runtime TTF, SVG, tween, web, JavaFX, Swing, or ImGui dependency.
- Do not perform broad screen migration before the Gate 17.5C vertical-slice
  approval. Gate 17.5B.5 must first establish and receive human approval for a
  world-first title-screen composition.
- UI SFX, gameplay chisel SFX, Fusion/CJK packaging, and Kenney Sci-Fi import are
  deferred.
- Every external source records upstream tag/commit, optional Git blob SHA,
  source-byte SHA-256, license, local path, derivative path/hash, and conversion
  command. Git object IDs never substitute for byte SHA-256.
- Preserve OpenGL context-owner GPU lifetime and macOS OpenGL 4.1 compatibility.
- Do not stage, commit, push, open a PR, merge, tag, or release without separate
  authorization. Commit steps are intentionally omitted from this plan.
